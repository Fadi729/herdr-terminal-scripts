# Scripts have a Name, not an id

The Catalog is hand-edited JSON. SuperSet can hide a UUID because a GUI allocates it; we cannot. Slots already follow Visible list order, so a stable id would not drive hotkeys. Two “Dev server” Scripts for two clones are the intended case. Identity is the list entry; Name is the label and may repeat. The Popup only shows the Matcher (or Global) when two Visible Scripts share a Name.
